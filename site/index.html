INSTALL FOR

Replace this with your project’s path, relative to the cloned collection or absolute.

POWERSHELL
git clone https://github.com/vannt-dev/ai-engineering-skills.git
cd ai-engineering-skills
pwsh -NoProfile -File ./scripts/install-skills.ps1 -Target Universal -Scope User -WhatIf

Requires Git and PowerShell. Run in PowerShell on Windows, macOS or Linux. In Windows PowerShell 5.1, replace pwsh with powershell.

After reviewing the preview, turn off “Preview first” to install. Existing managed installations can be updated with -Overwrite; see the installation guide.
